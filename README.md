# TTS-speech

Локальная запись голоса и озвучивание текста своим голосом на английском и русском. В комплекте: Qwen3-TTS, CosyVoice 3, VoxCPM2 и программа записи с готовыми текстами.

## Запуск двойным щелчком

Скачайте этот репозиторий целиком через **Code → Download ZIP** и распакуйте архив. Не запускайте файлы прямо из ZIP.

| Система | Что открыть |
|---|---|
| **Windows 10/11, x64** | **`START-WINDOWS.cmd`** |
| **macOS, Apple Silicon** | **`START-MACOS.command`** |

Откроется меню в браузере. Нажмите кнопку нужной программы:

- **0 · Записать мой голос** — микрофон, тексты, прослушивание, сохранение.
- **1 · Qwen3-TTS** — начните с этой модели для первого теста.
- **2 · CosyVoice 3** — альтернативное звучание.
- **3 · VoxCPM2** — ещё один вариант клонирования.

Терминал открывается автоматически; вводить команды не нужно. Оставьте его открытым, пока работаете. Для остановки нажмите **Ctrl+C** в этом окне. Программы, запущенные этим меню, завершатся вместе с ним; уже работавшие отдельно программы меню не останавливает.

## Что происходит при первом запуске

Запускатель скачивает [uv из официального релиза Astral](https://github.com/astral-sh/uv/releases/tag/0.13.1) и проверяет SHA-256 архива. Через uv при необходимости устанавливается Python. Права администратора и изменение системной политики PowerShell не требуются.

После выбора программы автоматически загружаются её исходники и устанавливаются зависимости в отдельное окружение. FFmpeg добавляется из пакета `imageio-ffmpeg`, если его нет в системе. Веса загружаются только при первом выборе соответствующей модели. Для программы записи веса моделей не нужны.

Полная загрузка трёх моделей — около **14 ГиБ** весов; вместе с окружениями и кэшем предусмотрите **30 ГБ свободного места**. Скачивание может занять десятки минут. Ход установки и ошибки видны в разделе **«Журнал запуска»**. После прерывания снова нажмите «Открыть»: загрузка весов продолжится через кэш Hugging Face.

На уже настроенном компьютере готовые окружения и веса используются повторно. На этом Mac генерация всех трёх моделей проверена на английском и русском.

## Windows

1. Распакуйте папку, например в `C:\TTS-speech` или в папку на рабочем столе.
2. Дважды нажмите **`START-WINDOWS.cmd`**.
3. Выберите программу в браузере.

Python, Git и CUDA устанавливать вручную для базового запуска не нужно. Нужны интернет при первой установке и обычный браузер с доступом к микрофону.

Windows использует собственные окружения `.venv-windows`; окружения `.venv` с Mac не подходят и не перезаписываются. Переносить готовые веса из папки `models` между системами можно.

Предусмотрен запуск через CPU. CUDA используется моделью, если установленная сборка PyTorch и видеокарта её поддерживают; для ускорения на конкретной NVIDIA может понадобиться отдельная настройка PyTorch. Windows ARM не проверялся. Полная генерация моделей на Windows пока не проверялась на физическом компьютере.

## macOS

1. Распакуйте папку в доступное место.
2. Дважды нажмите **`START-MACOS.command`**.
3. Выберите программу в браузере.

Проверенная конфигурация — **Apple Silicon, 24 ГБ памяти**. Qwen и VoxCPM используют MPS, CosyVoice — CPU. На Intel Mac поддержка зависимостей моделей ограничена и не проверена.

В существующей папке также доступны короткие команды `0 — Записать мой голос.command`, `1 — Qwen3-TTS.command`, `2 — CosyVoice.command`, `3 — VoxCPM.command`: они открывают нужную программу через тот же запускатель.

Если macOS сообщает о запрете запуска, проверьте источник файлов и используйте штатное разрешение macOS для доверенного приложения. Не отключайте системную защиту целиком.

## Запись своего голоса

1. Откройте **«Записать мой голос»**.
2. Выберите **English** или **Russian** и текст для чтения.
3. Нажмите **Record**, разрешите микрофон, прочитайте абзац, нажмите **Stop**.
4. Прослушайте и нажмите **«Сохранить образец»**.

Каждый дубль — от 2 до 30 секунд; удобно читать абзац за 10–20 секунд. Записывайте языки отдельно, обычным голосом и со своим привычным акцентом. Если произнесли другие слова, исправьте расшифровку перед сохранением.

В списке текстов есть **«MsFEM — часть 1» … «MsFEM — часть 4»**. Это связный короткий рассказ о многомасштабном методе конечных элементов, разбитый на отдельные дубли. Полный текст: [MSFEM-EN-RU.md](MSFEM-EN-RU.md).

Записи сохраняются как WAV, 24 кГц, моно, вместе с TXT и JSON в `samples`.

## Озвучивание нового текста

1. Откройте Qwen3-TTS, CosyVoice или VoxCPM.
2. Выберите сохранённый образец. После новой записи нажмите **«Обновить образцы»**.
3. Введите новый текст. Для Qwen выберите язык озвучки.
4. Нажмите **«Создать голосовое»**.

Результат сохраняется в `generated`. Если интерфейс был запущен до добавления выбора сохранённых образцов, один раз перезапустите его. Запускайте генерацию только в одной модели одновременно, чтобы хватало памяти. Для моделей желательно 24 ГБ оперативной памяти или больше.

Короткая запись используется как образец голоса; это не дообучение весов. Текущий запускатель устанавливает компоненты для записи и генерации. Подготовка обучения — отдельный этап.

## Где находятся файлы

| Папка | Содержимое |
|---|---|
| `samples` | Личные записи, расшифровки и метаданные |
| `generated` | Созданные голосовые WAV |
| `models` | Веса моделей |
| `logs` | Журналы запуска и установки |
| `cache`, `.tools` | Загрузки и служебные инструменты |
| `Qwen3-TTS`, `CosyVoice`, `VoxCPM` | Автоматически скачанные исходники и окружения |

Эти папки исключены из Git. Ваши голосовые записи и веса не загружаются в репозиторий. Интерфейсы слушают только `127.0.0.1`; публичные ссылки не создаются. После установки синтез использует локальные веса.

## Если что-то не запускается

- **Загрузка прервалась:** снова откройте запускатель и нажмите кнопку программы.
- **Микрофон недоступен:** разрешите доступ браузеру в его настройках и в настройках конфиденциальности ОС; попробуйте Chrome или Safari на Mac, Chrome или Edge на Windows.
- **Не хватает памяти:** закройте другие модели и тяжёлые программы.
- **Ошибка установки:** откройте «Журнал запуска»; полный файл находится в `logs/launcher-ИМЯ.log`.
- **Порт занят другой программой:** освободите соответствующий порт и повторите запуск.
- **Меню уже открыто:** повторный запуск открывает существующее меню.

Адреса: меню `http://127.0.0.1:7859`, запись `:7860`, Qwen `:7861`, CosyVoice `:7862`, VoxCPM `:7863`.

## Исходные проекты и проверка

Исходники и веса закреплены по версиям в `projects.json`; загрузка происходит из официальных репозиториев [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS), [CosyVoice](https://github.com/QwenAudio/CosyVoice), [VoxCPM](https://github.com/OpenBMB/VoxCPM). Их лицензии находятся внутри соответствующих проектов и карточек моделей. Запускатель применяет совместимые с локальной генерацией изменения CosyVoice: отключает ненужную загрузку нормализатора и откладывает импорт тренировочной зависимости `pyworld` до её использования.

Проверка запускателя без загрузки моделей:

```text
START-WINDOWS.cmd --check
```

```sh
./START-MACOS.command --check
python3 -m unittest discover -s tests -v
```

CI проверяет входные скрипты и запускатель на Windows и macOS. Доступ к настоящему микрофону и полная генерация всех моделей в CI не тестируются.
